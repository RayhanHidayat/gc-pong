# (On Progress) Pong-Like Video Game

This is a repository where I challenge myself to build my own Pong-like video game.

## Building the App

1. You need to have a C compiler (I use mingw64)
2. You need to add Raylib at the vendor folder
3. Run script below

```bash
mingw32-make
```
